# Codex 状态、项目与工作树

官方资料核对日期：2026-11-14。运行时能力和路径优先，不能依赖某个历史私有数据库结构。

## 根与索引

[环境变量](https://learn.chatgpt.com/docs/config-file/environment-variables)说明CODEX_HOME保存配置、认证、日志、会话和skills；CODEX_SQLITE_HOME可能另指数据库位置，配置`sqlite_home`又可覆盖环境变量。因此不只保护默认`~/.codex`，还要确认真实根和迁移入口。画像工具保护显式传入/环境可发现的根，但不会读私有数据库去推断全部关系。配置另设数据库根时，agent调用本工具应以真实位置设置该次进程的CODEX_SQLITE_HOME保护提示，不改用户持久环境。

执行器拒绝把状态根或内部目录当项目，也保守拒绝选中包含已配置状态根的父目录，避免普通名称的状态子目录绕过保护。遇到此情况，保留状态并选择能独立证明边界的实际项目子目录，不能取消环境保护或改名绕过。真实worktree的窄例外仍依照当前宿主和工具条件核实。

会话、归档、history、索引、SQLite和sidecar不是普通项目缓存；不得直接删旧JSONL、截断正文、改索引、执行VACUUM或写库修复。文件很大不代表不被引用，不靠文件名或时间认定孤儿。`history.max_bytes`只控制文档所述历史文件，不限制所有会话和数据库。

源代码、依赖或工具产物与Codex状态分开计量。agent运行的解码/渲染/下载脚本产生的大目录，不应无依据归因于Codex程序本身。必要时对真实写入路径做前后同范围快照，不抓全部聊天正文。

## 工作树

[Codex工作树机制](https://learn.chatgpt.com/docs/environments/git-worktrees)允许并行检出，每份可能各有依赖/缓存。根可配置；不能假定CODEX_HOME/worktrees包含全部。Git链接/commondir说明共享元数据关系，不沿指针递归清理外部仓库。

先用宿主当前提供的只读工作树/会话能力确认对象、活动/固定/共享关系和未完成内容。工具只列当前聊天附属工作树时，不能把结果当全局列表。无支持能力时给用户界面步骤，不硬编码工具名或私有API。

如宿主确有支持的归档入口，调用前读取其当前描述。某些入口会为本地修改、未推送提交和**未忽略**的未追踪文件保存可恢复快照，但不保存需要另存的ignored文件。必要ignored素材、环境补丁、实验/恢复产物先核实并保护；不能把“有快照”说成全部资料已保留。主工作区、活动、固定、共享、含初始化子模块/嵌套仓库等受限对象遵循当前宿主限制。

用户选择明确的已完成工作树后，按工具支持方式归档，检查聊天仍可用、快照恢复范围和实际空闲变化。不能默认归档当前活动聊天，也不能用递归文件删除或`git worktree remove`替代Codex管理流程。归档对话与释放工作树并非同一事实，各自验收。
