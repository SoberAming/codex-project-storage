# 1.5.0 · Agent 开发产物清理

本版把主流程收敛到Agent开发和任务执行产生、已经失效或冗余的产物。项目画像仍用于确定范围和解释占用；普通文档迁移不再是默认优化目标。

## 实际功能变化

- 新增Agent任务残留审查队列，识别暂存运行、截图录制、轨迹、下载碎片和测试/构建线索，复用已有互斥计量；候选不直接变成可释放量。
- 新增独立`agent_artifact_guard.py`执行器，支持精确、已结束任务中的限定残留。绑定真实生产与终止记录、保留成果、引用和读写条件，并核验完整成员、身份、内容及计划授权；范围改变即停止，保留回执。
- 新路线可处理最近结束的合格任务，不统一等待48小时。原有缓存、媒体与PG测试退役路线保持自己的资格条件。
- 补跨Agent保守状态名称、已配置/显式发现状态根及管理IO保护，防止计划、证据或回执绕进会话、索引、凭据存储。
- 安装包实际包含新执行器和规则，Windows/macOS四格CI实际执行新增发现、清理、状态边界套件，保留已有原生npm等测试。

## 范围

名称、日期和大小不是无效证明。未知布局、有效成果、当前使用、业务/状态数据库、会话、索引、唯一AI生成物和恢复资料继续保留。自动执行仍为明确支持的类型，其他产物可以诊断并给专用方案，不能宣称任意Agent文件均可清理。

多宿主使用其实际安装入口与权限；脚本跨平台验证和每种宿主业务验收分开。旧历史会话无需迁移或修改。工具不会自动开启后台清理、停止进程或改项目配置。

## 验证

查看[精确提交的CI](https://github.com/SoberAming/codex-project-storage/actions/workflows/ci.yml)、[兼容性说明](COMPATIBILITY.md)及该发布的CI证据附件。Windows/macOS各Python3.10与3.13必须通过；平台不适用项列为跳过，不混入通过。真实用户项目、会话与索引不用于破坏性验证，所有删除均限新建隔离样本。
