# v1.3.0 · 项目磁盘管家

项目空间越用越大时，让Agent先查明占用、用途和保留价值，再由用户选择删除、迁移或组合方案。

本版本面向代码、网页、视频、设计、研究和数据项目。识别依赖、环境、Git、构建、媒体和任务产物；不预设盘符，不将同卷换目录计作腾盘，也不要求用户逐个判断技术文件。

## 主要能力

- 有上限的跨工具链项目画像，兼容没有标准manifest的目录。
- 核实实际源卷、可用位置和迁移条件，分别解释独占、共享与未知数据。
- 严格CPython缓存、部分可本地确定重建的媒体中间产物精确清理。
- 满足真实专用归属和受支持版本条件时，调用pip自身管理缓存；uv/npm当前仅建议。
- 停用产物迁移和已核实冗余释放；迁移完整核验与用途验收后才释放源。
- 会话、索引、数据库、凭据、源码、原件、恢复、验收和唯一AI结果默认保护。
- 中英文安装/使用说明、贡献与安全规范、反馈模板、隔离测试和发布工具。

## 验证与限制

原始核心版本在Windows / Python3.13.13隔离样本上完成116项测试，114通过，2项因样本盘缺少链接能力而跳过；另有新建专用pip缓存的真实小样本清理与冻结组件独立试用。

公开版已增加Windows/macOS、Python3.10/3.13隔离测试矩阵，实际状态以该发布commit的Actions结果为准。首次Mac运行发现并修复了无扩展ACL的兼容分支，仍拒绝对象缺失、身份漂移、权限和I/O错误，未取消ACL检查。发布工具和15项ACL回归不混入原始核心116项。个人Mac设备、外部磁盘和真实业务工作流尚未完成验收。

类型识别覆盖广于自动执行。依赖、共享模型、数据库、未知构建目录和活动工程不自动通删；保护规则不能替代对真实用途、引用和静止条件的核实。

## 下载与安装

普通用户下载`codex-project-storage-1.3.0.zip`和`SHA256SUMS`，核对后按[安装指南](INSTALLATION.md)放入宿主支持的Skill根。开发者使用完整源码和[贡献指南](../CONTRIBUTING.md)。
