# 安全设计与能力边界

本工具面向误判、配置漂移、文件变动、错误卷、共享数据误归属和运行中资料误删等常见风险，不承诺识别所有私有格式或对抗具有同级权限的恶意写入者。

## 谁负责什么

| 判断或保证 | 责任与限制 |
| --- | --- |
| 数据实际用途、业务价值、外部引用、重建依赖 | Agent查真实说明、配置与生产记录，用户决定业务结果；JSON中的true不替代证据 |
| 受支持格式、保护目录、身份、成员、预算、哈希与执行一致性 | 对应执行器在其合同内校验；不同路线规则不同 |
| 项目与目标在哪个卷 | 使用实际卷身份；路径、盘符和目录名不证明物理设备类型 |
| 使用中的文件和并发变化 | Windows使用守护句柄；macOS为协作锁并要求静止证据；不保证阻止非协作写入者 |
| 历史与项目恢复 | 会话、索引、业务和状态数据库、源码、素材与恢复资料保护；可丢弃合成测试data须通过独立正向资格，工具不是完整备份系统 |

## 默认保护

保护会话/索引/SQLite及sidecar、认证、源码、原件、环境/依赖、恢复、交付/验收/视觉基准、唯一AI或实验结果。记录真实CODEX_HOME和独立数据库根；配置`sqlite_home`另设位置时，以该次工具进程CODEX_SQLITE_HOME提供真实保护位置，不修改用户持久环境。

执行器拒绝把已配置状态根、内部目录或包含状态根的父目录重新指定为项目，也拒绝把依赖子树重标为独立工程。不可通过改名、删标记或取消环境提示绕过拒绝。宿主管理工作树的有限例外须按当前支持方式核实，必要ignored文件另存。

画像只在范围和预算内读取元数据及允许配置，不读取会话、凭据或客户文档正文；全局共享路径默认仅存在性发现。项目外`--related-root`授权是测量授权，不是删除授权。

## 删除、迁移和停止

只对受支持且核实的对象生成计划。删除中间件须保留独立输入和生产依据，48小时硬下限不能靠修改时间规避。唯一模型结果、外部服务依赖或未保留输入的对象不进入该路线。

迁移保留源直到完整内容核验和用途验收通过。权限保真降级、外盘断连和取回方式须在方案说明；不默认把文件内容一致称为完整元数据备份。原生pip路线要求真实专用生产历史，不得事后补造标记/收据。

1.4的测试退役路线只针对独立资格核验的合成PG测试data。生产器、合成输入、真实的对应运行结束记录与当前引用/活动证据必须绑定；布尔声明、没有PID文件或当前版本的生产脚本都不能单独证明某次历史运行可丢弃。完整数据布局以外的独有笔记、种子、结果、日志或恢复资料使该范围不合格。工具不会连接数据库来判定业务价值，也不会执行项目重建来自动证明合成性。

npm路线使用独立原生命令合同，保留cache根的日志及其他数据；同卷隔离重命名本身释放0字节。原生清理失败或部分删除时报告实际位置、已完成与不确定项，不将隔离副本说成完整可恢复备份，也不盲目重试。`--force`是npm清空缓存要求的固定参数，不覆盖本工具的计划、静止、范围或用户决策条件。

遇到成员或身份漂移、I/O错误、断连、锁冲突立即停止；不自动提权、结束应用、解锁或重试。回执中的`delete_pending`可能是不确定结果，先核对原操作，不对整个计划盲目重放。发生CRC/bad block/EIO时停止大文件哈希、清理和压缩，先保护数据。

## 成果口径

逻辑字节、已知分配估计、复制量和源卷空闲差值分别说明。硬链接、压缩/稀疏、APFS共享块/快照、回收站和同期进程写入会影响实际回收。复制留源、同卷换目录、计划生成和同卷回收站不算已释放空间。

本工具不提供对所有设备的零风险保证。当前测试平台与跳过项见[兼容性](COMPATIBILITY.md)。漏洞或潜在误删反馈见[安全报告](../SECURITY.md)。
